# 网易BUFF交易信息爬取练习

这是一个用于学习 Python 爬虫的数据采集**练习项目**。

项目目标是通过爬取网易BUFF平台上的 CS2 饰品交易信息，学习网页数据获取、解析、数据存储以及数据处理流程。

## 项目介绍

本项目目前实现了对网易BUFF部分商品交易信息的采集，并将数据保存到本地数据库。

主要用于学习：

- Python 爬虫开发
- 网页数据解析
- 数据清洗
- MySQL 数据存储
- 爬虫项目结构设计

## 使用技术

- Python
- DrissionPage
- PyMySQL
- MySQL
- Regex
